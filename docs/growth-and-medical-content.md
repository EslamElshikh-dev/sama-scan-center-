# تحسين صفحات الفحوصات وقياس التحويل

## التشغيل

- الإدارة: `/dashboard?view=growth`، تبويبات اعتماد المحتوى الطبي، قياس الخرائط، واستيراد قياس Google. الاستقبال والإدارة: `/dashboard?view=crmreports` لعرض مقارنة أسبوعين متساويين.
- أربع مسودات خدمات خاصة جاهزة. املأ الفحوص المتاحة، التحضير، آلية إصدار الصور والتقرير، والمدة إن تأكدت. اختر صورة من أصول المركز الحالية بعد تأكيد أنها للجهاز المقصود. أضف مرجعًا واسم من أكد المعلومات وتاريخًا ثم اعتمد. يظهر المحتوى خلال خمس دقائق.
- أضف الطبيب بالاسم والتخصص والمؤهل المؤكدين. مستند التأكيد خاص بالإدارة ولا يصل للقارئ. لا يثبت زر الاعتماد صحة البيانات بنفسه؛ يجب على مسؤول المركز التحقق من المستند والموافقة قبل اعتماده.
- افتح المقال كاملًا مع الطبيب ثم سجّل اسمه، تاريخ المراجعة ونسخة المحتوى بتاريخ آخر تعديل. يظهر اسم المراجع وتاريخه فقط عندما تتطابق النسخة ويبقى الطبيب معتمدًا. تغيير نسخة المقال يوقف عرض اعتماد قديم. لا يُعد وجود المراجع الطبية مراجعة شخصية للطبيب.

## الحجز والمصدر

طلبات الموقع تحفظ مصدر دخول الجلسة تلقائيًا. طلب الاتصال أو واتساب له وسيلة تواصل مستقلة ومصدر وصول يسجله الاستقبال حسب إفادة العميل. السؤال المقترح: «كيف عرفت المركز؟» لا تخمّن المصدر. السجلات التاريخية غير الموثقة تبقى كذلك. الحضور لا يُستنتج من مرور الوقت.

الـ131 ضغطة اتصال للفترة 4 سبتمبر–3 أكتوبر 2026 إجمالي مجهول الهوية، لا يربط تلقائيًا بمراجعين أو 131 حجزًا. سجل الهاتف الفعلي مطلوب لقياس المكالمات المجابة والفائتة. المقارنة الأسبوعية تعرض ضغطات Google وطلبات CRM لنفس الأيام، دون قسمة الحجوزات على الضغطات كأنها تحويل لأشخاص متطابقين.

Google مستورد بمرجع وتاريخ ونسخة تحديث. بداية المقارنة الافتراضية هي أحدث أسبوع مستورد؛ يمكن اختيار أي أسبوع. عند غياب الاستيراد يظهر «غير مستوردة» وليس صفرًا. نتائج CRM تخص الطلبات المنشأة في كل أسبوع ونتيجتها الحالية، لا كل زيارات المركز خلاله؛ الأسبوع الأحدث قد ينتظر مواعيده. كل طلب يحسب مرة، والموعد المؤكد منفصل عن الحضور والفحص. المواعيد دون طلب مرتبط تظهر كفجوة.

## الخرائط

ابدأ بنقاط ثابتة في المربع والملز والعليا والسليمانية. لكل قياس سجّل عبارة البحث بالحرف، الإحداثيات الفعلية، نقطة القياس، الجهاز، اللغة العربية، وقت القياس بتوقيت الرياض، الأداة أو طريقة تحقق موقع الباحث، عمق النتائج ودليلًا. لا تستبدل موقع الباحث بمركز عرض الخريطة. استبعد الإعلانات. «خارج العمق المفحوص» مختلف عن «لم يُقَس بعد». قارن فقط نفس النقطة والكلمة والجهاز والعمق. لم تُزرع أرقام ترتيب افتراضية.

## الإصدار

طبّق migration `growth_content_and_weekly_measurement` ثم حدّث Edge Function `samascan-crm` بنفس إعداد المصادقة السابق، ثم انشر Next.js. قاعدة البيانات تمتد داخل مخططات Sama Scan فقط. جميع الجداول الجديدة RLS وبدون صلاحيات anon؛ دالة القراءة العامة الوحيدة تعرض حقول المحتوى المعتمد فقط، ولا تقرأ CRM أو الإثباتات أو الخرائط. إجراءات الاعتماد للإدارة فقط، والتقرير الأسبوعي للإدارة والاستقبال. جلسات التسويق لا تقرأ بيانات المرضى.

الاختبارات: `npm run test:crm` و`npm run typecheck` و`npm run lint` و`npm run build`. بيانات الاختبار معزولة وتتراجع بالكامل، دون إنشاء مراجع أو حجز في التشغيل.
