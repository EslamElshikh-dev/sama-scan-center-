# نتائج منشورات ملف Google

## النتيجة

يضيف تقرير نتائج المصادر تبويب «منشورات ملف Google»، لتجميع الطلبات التي حُفظ معها مصدر `google_business_profile` بحسب `campaign` و`content`. يعرض الطلب والحجز والموعد المؤكد والحضور وإتمام الفحص، ويمكن تصدير المقارنة. الوسوم الحالية للعرضين ورابط الحجز والرئيسية لها تسميات واضحة؛ الوسوم الأخرى تبقى ظاهرة للمراجعة.

لا يُنسب طلب يدوي أو ضغطة Google مجهولة إلى منشور تلقائيًا. الوسم المفقود يظهر في صف مستقل. كل طلب يُحسب مرة في كل مقياس، حتى عند الإلغاء وعدم الحضور ثم إعادة الحجز. الحضور وإتمام الفحص يتطلبان حالة مسجلة وموعدًا مرّ توقيته. تأكيد موعد مستقبلي لا يعني حضورًا.

## النشر والتحقق

1. مقارنة تعريف وظيفة `public.samascan_outcome_report(text,text,jsonb)` الحالية بالمصدر قبل الترحيل. طابق تعريف التشغيل خط الأساس المراجع عند الفحص بتاريخ 31 أكتوبر 2026.
2. تطبيق الترحيل `20261031070040_gbp_post_outcomes.sql`. يوسّع الوظيفة الموجودة فقط، دون جداول جديدة أو صلاحيات أوسع أو تغيير سجلات المرضى.
3. تشغيل فحوص المستودع ومراجعة العرض قبل دمج النسخة ونشرها على مشروع Vercel الحالي `samascan`.
4. التحقق من حدود الوصول ومن ناتج التقرير التجميعي عبر صلاحيات الإدارة القائمة. لا تُنشأ بيانات مراجعين تجريبية في التشغيل.

إذا نُشرت الواجهة قبل تحديث الوظيفة فستعرض أن تفصيل المنشورات ينتظر التفعيل؛ لا تحول البيانات غير المتاحة إلى أصفار.

## التحقق المحلي

اجتازت الإضافة 27 اختبارًا عبر `npm run test:crm`، منها التجميع حسب الحملة والوسم، وإعادة الحجز، والمواعيد المستقبلية، والوسم الناقص، والتواريخ، وحدود الصلاحيات في قاعدة PGlite معزولة. اجتازت أيضًا 6 اختبارات HTTP عبر `npm run test:release`، وفحص lint وبناء الإنتاج. تتراجع جميع بيانات الاختبار؛ يُستكمل التحقق البصري من نسخة المعاينة قبل النشر.
